# Continuity — safe shutdown

ColdByte's paid apps check their licence with https://coldbyte.dev.

If ColdByte ever stops, a signed **safe-shutdown notice** will be published in this folder as `sunset.token`.
Every copy of a ColdByte app that can no longer reach coldbyte.dev then unlocks for good: any PC, no key, no internet, no server.

- The notice is signed with ColdByte's private key. Nobody else can make one, and apps ignore anything unsigned.
- **Today there is no `sunset.token` here — ColdByte is active.**

# الاستمرارية — الإغلاق الآمن

تطبيقات ColdByte المدفوعة تتحقق من الترخيص عبر https://coldbyte.dev.

إذا توقفت ColdByte يومًا ما، سيُنشر في هذا المجلد إشعار «إغلاق آمن» موقّع باسم `sunset.token`، فتصبح كل نسخة لا تستطيع الوصول إلى coldbyte.dev مفتوحة للأبد: على أي جهاز، بلا مفتاح ولا إنترنت ولا خادم.

- الإشعار موقّع بالمفتاح الخاص لـ ColdByte، ولا يستطيع أحد غيرها إنشاؤه، والتطبيقات تتجاهل أي ملف غير موقّع.
- **لا يوجد اليوم ملف `sunset.token` هنا — ColdByte تعمل.**
